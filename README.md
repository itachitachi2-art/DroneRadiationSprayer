# Drone Radiation Sprayer

7 Days to Die v3.3向け、独立したドローン用アタッチメントMOD。
開発用名称：DroneRadiationSprayer。DLL版：0.1.0.1。パッケージ改訂：gun-sound1-candidate。
銃声変更パーツ24種類を追加した実機確認用候補です。新機能の仕様・導入・未確認事項は [GUN-SOUND-1.md](GUN-SOUND-1.md) を最初に読んでください。
今回も採用済みDLLとC#ソースは変更していません。以下は既存ドローン装置の仕様です。
Excuse Me, Droneの変更版ではなく、別フォルダ・別DLL・別Harmony IDで動きます。

## 仕様

- ドローン用パーツ1種類（別途、銃用の銃声変更パーツ24種類）。ドローンの改造枠を1つ使用します。
- 散布剤・弾薬・燃料などの消耗品は不要です。
- 稼働中のドローンの位置から半径25mの球形範囲。上下方向の距離も含みます。
- 被爆・チャージド・インフェルノのゾンビ型が対象です。警官系も含みます。
- 既存の回復阻害 `buffRadiatedRegenBlock15` を、およそ1秒ごとに更新します。
- 範囲を離れる、パーツを外す、ドローンを収納・停止する場合、最後の効果が最大15秒残ります。これは既存バフの持続時間です。
- 壁越しも距離内なら対象です。視線判定や強制的なチャンク読み込みは行いません。
- 待機指示中も、ドローンが正常に稼働していれば散布します。所有者との独自の距離制限はありません。
- 複数台の範囲が重なっても同じ対象への更新を約1秒に1回へまとめ、効果時間を加算しません。

## 「バニラの除去準拠」の範囲

回復阻害の内容・15秒の持続・ネットワーク送信はゲーム標準の処理です。
HP減少、ダメージ、攻撃対象、報復対象、起床命令を追加するコードはありません。
ただしゲーム内での睡眠・索敵・他MODとの組み合わせは未検証です。

既存の除去で止まらない回復は変更しません。v3.3のBusinessMan／UtilityWorker系にある直接回復（1.4HP/秒）は残ります。
プレイヤー・トレーダー・動物・被爆したハゲワシは対象外です。
別MODが追加した友好的なゾンビ型についての互換性は保証していません。

## 入手と取り付け

この候補版はクリエイティブ入手のみです。レシピ・材料・戦利品・トレーダー販売はまだ追加していません。

1. クリエイティブメニューで「ドローン用放射能除去散布装置」または `modDroneRadiationSprayer` を検索します。
2. ドローンを回収し、改造画面の空き枠に取り付けます。
3. ドローンを配置します。所持品・ドローンの荷物に入れただけでは動きません。

専用の散布音・粒子・モデルは付属しません。アイコンは本MOD専用の放射能除去散布装置です。
品質による性能差はありません。同じ装置を複数装着しても範囲や強さは増えません。

## 停止条件

- 故障・停止処理中・回収中・未配置・アンロード中
- 所有プレイヤーが不在、切断、死亡、アンロード中
- テレポート／NoClipなど通常稼働以外の状態
- HPが2以下

HP2以下の停止は安全策です。Excuse Me, DroneのF10故障機回収は一時的にHP2へ復帰するため、その間の誤散布を避けます。
通常のドローンもHP2では散布しないので修理してください。Excuse Me, Drone自体は不要です。

## 導入

1. ゲームとサーバーを終了し、セーブをバックアップします。
2. ZIP内の `DroneRadiationSprayer` フォルダを使用中の `Mods` フォルダへ置きます。
3. `Mods/DroneRadiationSprayer/ModInfo.xml` と `DroneRadiationSprayer.dll` があることを確認します。
4. EACを無効にして起動します。ゲーム同梱の `0_TFP_Harmony` が必要です。

旧版から更新するときは、終了後に既存の `DroneRadiationSprayer` フォルダを別の場所へ退避し、新版のフォルダを丸ごと配置してください。Config/Localization.csv を読み込むため、ゲームを完全に再起動します。旧Localization.txtは新版に含めません。
日本語では「ドローン用放射能除去散布装置」、英語では「Drone Radiation Sprayer」をクリエイティブメニューで検索してください。

DLL・XML追加MODなので、マルチではサーバーと参加者の両方に同じ版を導入してください。
散布判定はサーバー側のみで、標準のバフ同期を使用します。Dedicated Serverでの実プレイは未検証です。
ゲーム本体やHarmonyのDLLはこの配布物に含めていません。

## 外し方

MODを入れた状態で全ドローンからパーツを外し、この追加パーツを所持品・保管箱などから処分してセーブします。
ゲームとサーバーを終了後、`Mods/DroneRadiationSprayer` を退避します。問題があれば導入前のバックアップへ戻してください。
追加アイテムを残したままMODを外すと、ゲームが未知のアイテムを読めなくなる可能性があります。

## ビルド

完成DLLを同梱しています。ソースから再ビルドする場合だけWindowsで `build.cmd "ゲームのフォルダ"` を実行してください。
Windows標準Framework cscを使用し、ゲーム付属のManagedとHarmonyを直接参照します。
`/nostdlib+` とコマンドラインの `/noconfig`、UTF-8応答ファイルを使用します。
Windows上でのビルドスクリプト実行は未検証です。
